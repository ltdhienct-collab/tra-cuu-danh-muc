TRA CỨU DANH MỤC - BẢN WEB APP/PWA

Mục đích: chạy trên Android, iPhone và máy tính bằng trình duyệt.

Cách triển khai: đưa toàn bộ thư mục này lên một dịch vụ web tĩnh (ví dụ GitHub Pages/Cloudflare Pages/Netlify).
Sau khi có URL HTTPS, mở URL trên điện thoại và chọn Thêm vào màn hình chính/Cài đặt ứng dụng.

Lưu ý: dữ liệu ghi chú và To-Do của bản này được lưu trên từng thiết bị (localStorage), không tự đồng bộ giữa nhiều điện thoại.
Danh mục tra cứu được nhúng trong index.html như bản extension gốc. Chức năng dữ liệu hành chính có thể gọi API provinces.open-api.vn.
